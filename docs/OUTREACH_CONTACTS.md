# Outreach — locals first (farmers, chop bars, restaurants)

**Purpose:** Get real WhatsApp numbers and 10–15 min chats before finals / soft launch.  
**Tone:** Casual. You’re a student building AgroLink — not writing to a ministry.  
**Channel:** Walk-in + WhatsApp. No formal letters.

**Ask:** How they buy/sell tomato & leafy greens today · spoilage · would same-day pickup + MoMo help.  
**Target:** ≥5 farmers + ≥5 kitchens (chop bars / restaurants).
